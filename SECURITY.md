# Security Policy

## Supported versions

Zerlyth is in early development. Security fixes are currently applied to the latest commit on the `main` branch and the latest tagged release.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Report them privately through GitHub's private vulnerability reporting feature when it is enabled for this repository. If that feature is unavailable, contact the repository owner through the email address listed on the GitHub profile.

Include the Zerlyth version, operating system, command used, reproduction steps, and an explanation of the impact. Do not include secrets or private source code unless it is necessary to reproduce the issue.

Zerlyth is designed to operate locally without network access during analysis. Reports that cause unexpected command execution, unauthorized network access, source-code disclosure, or writes outside the requested output path receive priority.
